# scripts

`newman-trend-metrics.js` reads a Newman JSON report and emits two things: a GitHub Actions job-summary table (to `$GITHUB_STEP_SUMMARY`) whose Result verdict reflects all Newman failures (failed assertions, failed requests, or run-level failures), and a benchmark-action-compatible metrics file for the trend chart. Run the dependency-free test for the verdict logic with `node scripts/newman-trend-metrics.test.js`.

`check-collection-no-auth.js` (Layer 4 guard) lints a Postman collection to enforce the "unauthenticated public PokéAPI only" invariant so no credential can leak into the published report. Usage: `node scripts/check-collection-no-auth.js [collection.json]` (defaults to `postman/pokeapi.postman_collection.json`). It recursively collects every violation and flags: any `auth` block whose type is not `noauth` (at collection, folder, or request level); any request/folder header keyed `Authorization` or `x-api-key` (case-insensitive); and any host other than `pokeapi.co`, including a `base_url` variable that does not resolve to `https://pokeapi.co` (the `{{base_url}}` token is allowed). Exit codes: `0` clean, `1` one or more violations (all printed), `2` read/parse error. Run the test with `node scripts/check-collection-no-auth.test.js`.

`redact-report.js` (Layer 5 guard) masks secrets and PII in a Newman htmlextra HTML report before it is published to GitHub Pages. Usage: `node scripts/redact-report.js <input.html> <output.html>`. It replaces Bearer tokens, labelled `api-key`/`apikey`/`authorization`/`access-token`/`token`/`secret` assignment values, and email addresses with the literal `[REDACTED]`, prints a substitution count, and is conservative (status codes, `pikachu`, and assertion names survive) and idempotent (running twice is a no-op). Exit codes: `0` success, `2` usage/read error. Run the test with `node scripts/redact-report.test.js`.
